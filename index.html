The ESP32 firmware accepts printable ASCII, tabs and line breaks. Non-ASCII characters (including emojis and smart quotes) are rejected to prevent altered output. Line endings are normalized to LF.

Protocol: C (clear), A + up to 19 text bytes (append), E (finish). Each BLE write is acknowledged at the GATT transport level; this firmware does not yet return an application-level checksum/receipt. Only send text to devices you control.
