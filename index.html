Same firmware protocol: C / A + 19 bytes / E. Text limit: 6,000 bytes. Only printable ASCII, tabs, and newlines. Bluetooth acknowledgements confirm writes; where available, the page also checks your newer firmware's READY byte count.

Smart modes predict editor behavior; they cannot read your cursor position. Auto-closing quotes/brackets and auto-formatting can still interfere. When a line requires removing existing automatic indentation, this website blocks Smart sending rather than risk damaging code. That case needs editor configuration or future firmware support for Backspace.
